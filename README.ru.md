# AWS IP Ranges в Address-List для MikroTik

PowerShell-скрипт, который скачивает официальный JSON с диапазонами IP AWS и генерирует команды RouterOS для заполнения address-list. Вывод разбивается на `.txt`-файлы не более чем по 2000 строк, чтобы их можно было вручную скопировать и вставить в терминал MikroTik.

## 🧩 Зачем я это сделал

Я столкнулся с этой проблемой из-за блокировок Роскомнадзора. Игровые серверы и матчмейкинг **Warhammer 40,000: Darktide**, **Gray Zone Warfare** и **War Dogs** находятся за инфраструктурой AWS, которая была недоступна напрямую с моего провайдера. Вместо костылей (прокси на консоли, хаки под каждую игру, постоянное включение и выключение VPN) я направил только AWS-префиксы через туннель на своём MikroTik, а всё остальное — включая российские сервисы — оставил идти напрямую.

Этот скрипт сделал такую схему практичной: он поддерживает address-list AWS в актуальном состоянии без ручного копирования тысяч префиксов, поэтому игры запускаются и находят матчи нормально, а остальная сеть работает как обычно.

## 📋 Что он делает

1. Скачивает `https://ip-ranges.amazonaws.com/ip-ranges.json`
2. Опционально фильтрует по региону и/или сервису AWS
3. Удаляет дубликаты
4. Генерирует команды RouterOS: `/ip firewall address-list add list=<list> address=<prefix> comment="<comment>"`
5. Разбивает вывод на файлы не более чем по 2000 строк
6. Сохраняет их в указанную папку (создаёт её, если нет)

Имена файлов выглядят так: `AWS-30-10-2026-1.txt`, `AWS-30-10-2026-2.txt`, ...

## ✅ Требования

- Windows PowerShell 5.1 или PowerShell 7+
- Доступ в интернет к `ip-ranges.amazonaws.com`
- Права на запись в папку вывода

## 🚀 Использование

Запустите скрипт: `.\Get-AwsRanges.ps1`

Скрипт интерактивно спросит:

- **Имя address-list** (Enter = `Madbaza`)
- **Комментарий** (Enter = `AMAZON`)
- **Путь для сохранения** (Enter = `D:\AWS`)

Можно передать их сразу, чтобы пропустить вопросы: `.\Get-AwsRanges.ps1 -AddressList Madbaza -Comment AMAZON -OutputDir "D:\AWS"`

## ⚙️ Параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| `-AddressList` | `Madbaza` | Имя целевого address-list |
| `-Comment` | `AMAZON` | Комментарий, добавляемый к каждой записи |
| `-OutputDir` | `D:\AWS` | Папка для сгенерированных файлов |
| `-FilterRegion` | — | Включать только префиксы этого региона AWS (например, `eu-central-1`) |
| `-FilterService` | — | Включать только префиксы этого сервиса AWS (например, `S3`, `EC2`) |
| `-ShowSyncInfo` | выкл | Показать `syncToken`, `createDate` и общее число префиксов |
| `-MaxLinesPerFile` | `2000` | Максимум строк в одном выходном файле |

## 📝 Пример

`.\Get-AwsRanges.ps1 -FilterRegion eu-central-1 -ShowSyncInfo`

## 📥 Импорт в MikroTik

1. Откройте сгенерированный `.txt`-файл
2. Выделите всё (`Ctrl+A`), скопируйте (`Ctrl+C`)
3. Вставьте в терминал MikroTik (WinBox или SSH)

Файлы записываются **без BOM**, поэтому первая команда выполнится корректно при вставке.

Если хотите очистить список перед импортом, выполните на роутере: `/ip firewall address-list remove [find list=Madbaza]`

## 📌 Примечания

- Используются только IPv4-префиксы (массив `prefixes`). IPv6 (`ipv6_prefixes`) не включён.
- Скрипт ничего не удаляет на роутере — он только генерирует команды `add`.
- Дубликаты удаляются через `Sort-Object ip_prefix -Unique`.
